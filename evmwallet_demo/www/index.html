C-chain with any EVM wallet

Two wallets, one per chain. MetaMask holds the C-chain side and never signs anything Avalanche-specific: exporting to the P-chain is one ordinary contract call, and importing from the P-chain needs no signature at all. The P-chain side stays a normal P-chain wallet (Core, Ledger, an exchange) and signs its own transactions exactly as today. C → P: MetaMask exports with one contract call

You call exportToP(to) with AVAX attached. The contract emits a warp log with the P-chain owner and the amount. Nobody signs it. After the block executes, the SAE hook reads the log, debits the contract and writes a UTXO owned by to into shared memory. No ExportTx, no credential, no relayer. The export is done when the UTXO sits in shared memory.

P → C: nobody signs the import

Anyone, you, the wallet, a bot, posts an ImportTx with zero credentials. The C-chain accepts it only if every UTXO is marked, the single output pays exactly the owner, and the burned fee stays under a cap. Unmarked legacy UTXOs, whose 20-byte owner is a P-chain key hash nobody holds an EVM key for, still need a signature, so no funds can be swept to a dead address.
